# v0.23 — Three-Stage Match

- Kept Match as a single dashboard activity.
- Added a third game: **Memory Match**.
- Match now progresses through:
  1. Picture Match — word ↔ picture
  2. Meaning Match — word ↔ definition
  3. Memory Match — classic face-down word/picture pairs
- Memory Match uses the same six vocabulary items selected for the first two stages.
- Match completion is recorded only after all three stages are completed.
- Added responsive memory-card layout and move/pair counter.
