# v0.24 — Match variety + completion fix

- Picture Match, Meaning Match, and Memory Match now use different six-word sets.
- A full Match run therefore practises 18 vocabulary words when enough illustrated vocabulary is available.
- The 18 words are randomly selected each time Match is opened.
- The three sets are non-overlapping where the available vocabulary pool allows.
- The final completion screen now shows **3 / 3 games** instead of **6 / 6**.
- The final screen also reports that 18 vocabulary words were practised.
- Stage transition text now makes clear that the next game uses different words.
